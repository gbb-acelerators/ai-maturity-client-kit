# `collection/`: collection assets

🌐 English · [Português (Brasil)](README.pt-br.md) · [Español](README.es.md)

Framework v2 is the default collection flow.

| Asset | Purpose |
| --- | --- |
| [AI-Maturity-Form-Questions_v2.md](AI-Maturity-Form-Questions_v2.md) | Approved v2.0.2 source spec. |
| [AI-Maturity-Form-Questions_v2.pt-br.md](AI-Maturity-Form-Questions_v2.pt-br.md) | PT-BR translation of the spec. Sections 6 and 7 and the references are generated by `scripts/sync_spec_translations.py`. |
| [AI-Maturity-Form-Questions_v2.es.md](AI-Maturity-Form-Questions_v2.es.md) | Spanish translation of the spec, kept in step the same way. |
| [FORMS-INSTRUCTIONS.md](FORMS-INSTRUCTIONS.md) | Microsoft Forms, Excel, and offline merge setup for v2. The repository also has `FORMS-INSTRUCTIONS.pt-br.md` (PT-BR) and `FORMS-INSTRUCTIONS.es.md` (ES); each language package ships its copy under this name. |
| [question-bank.pt-br.md](question-bank.pt-br.md) | Generated PT-BR v2 question bank. |
| [question-bank.md](question-bank.md) | Generated English v2 question bank. |
| [question-bank.es.md](question-bank.es.md) | Generated Spanish v2 question bank. |
| [template-export-forms.xlsx](template-export-forms.xlsx) | v2 Microsoft Forms import template. |
| [v1/](v1/) | Archived v1 banks, instructions, and template. |

The offline form exports one respondent per `responses.json`. Collect exports in a folder and run `make merge DIR=exports/` before `make pipeline`.

Regenerate v2 collection assets with:

```bash
make generate-v2
```

Validate without changing files with:

```bash
make validate-v2
```
