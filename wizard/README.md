# `wizard/`: Implementation Guide Wizard (v2 Part 4)

🌐 English · [Português (Brasil)](README.pt-br.md)

**`WIZARD`** · _Custom Part 4_ · 📖 [🏠 Index](../README.md) · [« Learning Survey](../survey-learning/INSTRUCOES-FORMS-LEARNING.md) · You are here

This folder contains the generated trilingual wizard and JSON template used to personalize `saida/v2_implementation_guide.pdf`. The wizard runs offline and migrates old v1 browser storage.

> [!NOTE]
> Output in every mode: `implementation-guide-inputs.json` at the kit root. `make pipeline` detects it automatically and merges it into `payload_v2.json`.

## The 11 inputs

| # | Input | What it is |
| --- | --- | --- |
| 1 | `executive_steering_committee` | Sponsor, program lead, security, finance, change, and champion representatives. |
| 2 | `tpo` | Technology Product Owner or program office with decision authority. |
| 3 | `dimension_owners` | One line per owner, for example `D4: name, role`. |
| 4 | `raci_matrix` | Activities and R/A/C/I assignments. |
| 5 | `communication_plan` | Audience, channel, frequency, and owner. |
| 6 | `training_plan` | Cohorts, format, cadence, and criteria. |
| 7 | `adkar_notes` | Awareness, Desire, Knowledge, Ability, and Reinforcement notes. |
| 8 | `risk_register` | Table with Risk, Impact, Mitigation, and Owner. |
| 9 | `quick_wins_w1_4` | First 30 days. |
| 10 | `quick_wins_w5_8` | Weeks 5 to 8. |
| 11 | `quick_wins_w9_12` | Weeks 9 to 12. |

## The 4 modes

### A. Standalone HTML wizard

```bash
open wizard/implementation-guide-wizard.html
```

- Generated by `scripts/generate_v2_tools_html.py`.
- Language selector: EN, PT-BR, and ES.
- Saves drafts to `localStorage`.
- Downloads `implementation-guide-inputs.json` with the 11 fields.
- Empty fields remain empty and render as `to fill with the client`.

### B. Editable JSON template

```bash
cp wizard/implementation-guide-inputs.template.json implementation-guide-inputs.json
code implementation-guide-inputs.json
```

The generated template has empty values and guidance in `_guide` for EN, PT-BR, and ES.

### C. Conversation in Copilot Chat

Use `/wizard-implementacao` when you want Copilot to gather the fields in conversation and save the JSON after confirmation.

### D. Auto-fill from the Learning Survey plan

```bash
python3 wizard/scripts/auto_fill_from_plano.py --lang en
```

Mode D reads the latest `saida/plano-capacitacao-*.md`, fills 7 of the 11 fields from the Learning Survey training plan, and marks the rest as fill-in items. It uses active Champions for the steering committee, the calendar for communication, cohorts for training, ADKAR notes, and quick wins.

## After filling in

```bash
ls implementation-guide-inputs.json
make pipeline
```

v1 Part 4 also reads the new file and ignores fields it does not use.

## Skipping and reuse

- Skipping is allowed. Empty fields render as `to fill with the client`.
- You can fill only some of the 11 inputs and rerun `make pipeline`.
- Rerunning the wizard overwrites only the fields you save again.
