# Example outputs

🌐 English · [Português (Brasil)](README.pt-br.md) · [Español](README.es.md)

Every file here is generated by `python3 scripts/build_v2_examples.py` from illustrative inputs: the mock `responses.v2.json.example` (14 respondents, Contoso Engineering), the companion survey mocks, generated fixture repositories and `scripts/fixtures/copilot-usage-organization-28-day.mock.json`. None of it is real client data. Do not edit these files by hand.

The folder root holds the PT-BR example. [en/](en/) and [es/](es/) hold the same PDFs in English and Spanish. The archived v1 example is in [v1/](v1/).

## v2 reports (PDF)

| File | Content |
| --- | --- |
| `v2_assessment_summary.pdf` | Overall result, flags, persona heatmap, evidence cross-checks, Developer Survey context, backlog, strategies, references |
| `v2_roadmap_g1.pdf` | G1: D1, D2, D9 |
| `v2_roadmap_g2.pdf` | G2: D3, D4, D5 |
| `v2_roadmap_g3.pdf` | G3: D6, D7, D8 |
| `v2_implementation_guide.pdf` | Governance, phased plan by priority, change management, risks from the flags, success metrics and the first 90 days |
| `round-comparison.pdf` | Round comparison from the v1 example to the v2 mock (indicative baseline through the v1 lineage) |

The implementation guides in all three languages use wizard inputs filled by `wizard/scripts/auto_fill_from_plan.py` from the Learning and Growth Survey mock. For the EN and ES examples the survey mocks are answered as if the forms were built in that language (options translated through the banks and `survey-devs/options.json`); free-text answers stay as written.
