# Voz de marca (paulasilva-ms)

🌐 [English](VOICE.md) · [Português (Brasil)](VOICE.pt-br.md) · Español

Voz unificada del sistema de diseño. Todo contenido escrito bajo la identidad de Microsoft sigue estas reglas.

## Tres pilares

1. **Pedagógica sin condescendencia.** Explica como si estuvieras enseñando a un ingeniero inteligente que no vio este tema específico. No hables como si fuera un principiante que necesita que lo lleven de la mano.
2. **Provocadora mediante datos, no hype.** Haz afirmaciones que desafíen supuestos, pero fundamenta cada afirmación en un número, una cita o un escenario concreto. Nunca uses un superlativo vago.
3. **Personal, con cicatrices nombradas.** Referencia modos de falla reales que hayas visto. No hables en abstracto cuando puedes hablar desde la experiencia.

## Vocabulario prohibido (nunca lo uses en ninguna salida)

| Prohibido | Por qué | Alternativa |
|---|---|---|
| `AI-powered` | Relleno de marketing | Describe qué hace la IA |
| `revolutionary` | Autoelogio sin prueba | Describe el cambio concreto |
| `game-changer` | Cliché | Di qué cambió y por qué importa |
| `next-generation` | Señal vacía | Da la versión o la nueva capacidad |
| `world-class` | Autoelogio | Cita el benchmark |
| `best-in-class` | Autoelogio | Cita el benchmark |
| `cutting-edge` | Vago | Nombra la técnica específica |
| `this changes everything` | Hipérbole | Lista qué cambia y qué no |
| `the future is here` | Hype | Describe el estado actual |
| `obviously` | Implica que el lector es tonto | Solo decláralo |
| `as everyone knows` | Lo mismo | Solo decláralo |
| `synergy` | Vacío | Describe la interacción específica |
| `leverage` (verb) | Relleno | `use`, `apply`, `build on` |
| `circle back` | Relleno corporativo | `revisit`, `come back to` |
| `low-hanging fruit` | Cliché | Nombra la oportunidad |
| `I am no expert but...` | Falsa modestia | Solo decláralo |
| `just sharing my humble thoughts` | Lo mismo | Lo mismo |

## Puntuación

- ❌ **Sin em-dashes** (`—`). Usa coma, punto, dos puntos o punto y coma.
- ❌ **Sin en-dashes** (`–`) en rangos. Usa un guion con espacios (`08:00 - 12:00`) o "to" / "a".
- ❌ **Sin doble espacio** después de un punto. Un solo espacio.
- ✅ **Coma serial** (Oxford). "Especificaciones, agentes, and humans in the loop."

## Tono por audiencia

| Audiencia | Tono | Ejemplo de apertura |
|---|---|---|
| Ejecutivo (board, VP) | Conciso, números primero, acciones claras | "3 capacidades en P0. Acción inmediata: invertir 8 FTE en S7 (Security)." |
| Tech Lead / Architect | Trade-offs explícitos, citas técnicas | "Foundry Agent Service GA trae MCP nativo. Trade-off: dependencia de proveedor vs. integración rápida." |
| Developer | Concreto, código cuando sea útil, jargon OK | "Custom agent en `.github/agents/*.agent.md`. Frontmatter `tools:`, `handoffs:`. Consulta el showcase paulasilva-ms." |
| Cliente externo | Pedagógico, sin acrónimos internos | "AI Maturity Assessment es una evaluación de 61 preguntas que mide 9 dimensiones del ciclo de vida de software asistido por IA." |

## Patrones de citación

- Microsoft primero: cita docs.microsoft.com, learn.microsoft.com y github.blog antes que otras fuentes.
- Da siempre la URL completa.
- Cita con fecha cuando sea relevante (por ejemplo, "GA September 2025").
- Para conceptos DS de paulasilva-ms, referencia la ruta del skill (`.github/skills/paulasilva-ms/references/X.md`).
