# `referencia/exemplo-saida/es/`

Versión en español de los seis PDFs de referencia del framework v2, generados con `python3 scripts/build_v2_examples.py` a partir de entradas ilustrativas (ver [la carpeta de ejemplos](../README.md)). [« Carpeta de ejemplos](../README.md)

| Archivo | Contenido |
| --- | --- |
| `v2_assessment_summary.pdf` | Resultado general, flags, heatmap por persona, verificación cruzada de evidencias, backlog, estrategias, referencias |
| `v2_roadmap_g1.pdf` | G1: D1, D2, D9 |
| `v2_roadmap_g2.pdf` | G2: D3, D4, D5 |
| `v2_roadmap_g3.pdf` | G3: D6, D7, D8 |
| `v2_implementation_guide.pdf` | Guía de implementación sin entradas del wizard: muestra qué completar con el cliente |
| `comparacao-rodadas.pdf` | Comparación entre rondas del ejemplo v1 al mock v2 (indicativa) |

Los scripts de los surveys complementarios generan EN y PT-BR, por eso este ejemplo no trae contexto del Developer Survey ni entradas del wizard. El ejemplo v1 archivado (5 PDFs) está en [../v1/es/](../v1/es/).
